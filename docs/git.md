# Git 運用

## ブランチ方針

| 項目 | 決め方 |
|------|--------|
| GitHub Default branch | `dev` |
| PR 先（base） | `dev` |
| `main` | リリース用。日常 PR は向けない |

- 原則、1 Issue につきブランチ 1 本・PR 1 つ
- コミットメッセージは「何の変更か一目で分かること」

## プレフィックスの使い分け

| プレフィックス | 用途 |
|----------------|------|
| `docs/` | 仕様・手順・README など |
| `feature/` | バッチ実装・機能追加・テストなどコード変更全般 |
| `fix/` | バグ修正 |
| `refactor/` | 依存・設定・構成整理 |

## コミットメッセージ

形式:

```text
{emoji} {Type}: {日本語の要約}
```

| Type | emoji | 用途 |
|------|-------|------|
| Docs | 📝 | 仕様・手順 |
| Chore | 🔧 | 設定・土台 |
| Feat | ✨ | 機能追加 |
| Fix | 🐛 | バグ修正 |
| Update | 🔄 | 調整 |
| Refactor | ♻️ | リファクタ |
| Test | ✅ | テスト |
| Wip | 🚧 | 未完成の退避 |
