# 固定予定 JSON

トップレベルは配列、または `events` 配列を持つオブジェクトです。

```json
{
  "events": [
    {
      "title": "終日予定",
      "start": "2026-06-20",
      "uid": "all-day-sample"
    },
    {
      "title": "時間指定予定",
      "start": "2026-06-21T10:00:00+09:00",
      "end": "2026-06-21T11:00:00+09:00",
      "description": "説明",
      "location": "場所",
      "reminders": [30]
    }
  ]
}
```

`uid` は任意ですが、同じ予定を安定して更新するため、継続運用する予定には指定してください。
